# DCD provenance

This is an independent implementation of the differentiable constraints and
optimization procedure described in:

Rohit Bhattacharya, Tushar Nagarajan, Daniel Malinsky, and Ilya Shpitser,
*Differentiable Causal Discovery Under Unmeasured Confounding*, AISTATS 2021,
arXiv:2010.06978.

The authors' implementation was consulted for public defaults and matrix
conventions:
https://gitlab.com/rbhatta8/dcd/-/blob/master/admg_discovery.py

As inspected in August 2026, the authors' repository did not contain a license
file or declare a software license. Consequently, source code from that
repository is not copied into this project.
